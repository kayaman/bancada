# Bancada 0.23.1

A small focus polish on top of 0.23.0: the assistant panel now stays front-and-centre through the full build–flash–read cycle, so you never have to hunt for it after a compile finishes.

## Assistant

- After a successful or failed build the assistant tab regains focus automatically, matching the behaviour already in place when the assistant flashes a board. The build console is no longer the last thing on screen — the assistant's next turn is.
